## 0. Method and caveats

- Reachability was computed with my own import graph (scratchpad `graph.py`, `reach.py`, `only_via.py`): 1,231 TS/TSX/MJS files, 4,328 import edges (static imports, `import()`, `new URL()`); entry points = every `app/**/{page,layout,route,loading,error,not-found,opengraph-image,sitemap,robots,manifest,icon}` file + `middleware.ts` + `i18n/request.ts`; tests excluded from the graph. Dynamic `import(\`./${name}\`)` in `lib/prototyping/providers/index.ts` was added by hand.
- knip counts test imports as usage, so its 382/354 lists do NOT contain symbols used only by tests. I computed those separately (336 exports, section 3).
- "SAFE TO DELETE" = no import, no href, no string reference in app/components/lib/e2e/scripts/messages/next.config.mjs/middleware.ts/vercel.json, no data, no customer or admin route. Everything else goes to "NEEDS OWNER DECISION".
- i18n key liveness is a heuristic (last key segment looked up as an identifier/string in source). It cannot see keys built from variables except via the template-prefix list I extracted (230 prefixes). Treat counts as bounds.
- Helper scripts (not repo files): `g.sh`, `gs.sh` (grep wrappers), `graph.py`, `reach.py`, `only_via.py`, `exports.py`, `testonly.py`, `i18n_ns.py`, `i18n_keys2.py`, all in the scratchpad dir.
