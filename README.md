# Gestaltung

Manufacturing marketplace and inventory platform for Qatar.

Stage 1: Next.js 15 (App Router) + TypeScript + Tailwind CSS + shadcn/ui. A single
landing page, deployed to Vercel.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

See `Gestaltung_Build_Plan.md` for the full staged roadmap and `CLAUDE.md` for project context.
